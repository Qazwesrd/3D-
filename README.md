# 3D动漫角色创作大师

独立开发的桌面端3D动漫角色创作软件。当前从零建立工程，不依赖其他项目。

## 项目原则
- 独立源码、独立安装包、独立数据目录。
- 优先采用免费且许可兼容的开源技术。
- 未经用户明确授权，不调用付费API、不自动购买或充值。
- 以 Windows + AMD Ryzen 7 4800U / Radeon 集成显卡作为基础兼容目标，实际性能以设备测试为准。
- 第三方代码、模型权重、插件和素材逐项审核许可证；本工程许可证不覆盖第三方内容。

## 当前版本
v0.4 开发中：中文桌面界面、角色项目本地管理、OpenGL视口代码、本地3D网格导入、程序化人形生成、人体比例调节、成年男性/女性/少年/少女/儿童体型预设、基础眼睛/虹膜/鼻子/嘴部/耳朵、手指和脚部几何、身体部件独立导出（GLB/OBJ/STL）以及整模GLB导出代码。

当前人物仍是由基础几何体组合的灰盒模型，不是可直接用于影视或游戏生产的精细人体拓扑；尚无精细面部雕刻、头发、服装、盔甲、UV/PBR材质、骨骼绑定和动画。部件可独立导出，但目前尚未实现视口内的部件选择高亮、隐藏/显示或直接编辑拓扑。尚未在目标电脑完成实机验收。

## 启动
```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python main.py
```

## 目录
- `app/` 桌面应用程序
- `app/core/` 项目数据、硬件、模型加载和角色生成
- `app/services/` 引擎适配和服务
- `app/widgets/` UI组件与3D视口
- `tests/` 自动化测试
- `docs/` 架构、开发计划、许可证与验收文档
- `assets/` 自制或许可已核验的资源
- `models/` 许可已核验的模型权重
