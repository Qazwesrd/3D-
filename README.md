# 3D动漫角色创作大师

独立开发的桌面端3D动漫角色创作软件。当前从零建立工程，不依赖其他项目。

## 项目原则
- 独立源码、独立安装包、独立数据目录。
- 优先采用免费且许可兼容的开源技术。
- 未经用户明确授权，不调用付费API、不自动购买或充值。
- 以 Windows + AMD Ryzen 7 4800U / Radeon 集成显卡作为基础兼容目标，实际性能以设备测试为准。
- 第三方代码、模型权重、插件和素材逐项审核许可证；本工程许可证不覆盖第三方内容。

## 当前版本
v0.2 开发中：中文桌面界面、角色项目本地管理、基础硬件信息采集、OpenGL视口代码、本地3D网格导入代码。支持尝试导入 GLB、GLTF、OBJ、STL、PLY。当前仍属于开发阶段，未在目标电脑上完成实机验收；复杂PBR材质、纹理、骨骼动画和编辑功能尚未完成。

## 启动
```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python main.py
```

## 目录
- `app/` 桌面应用程序
- `app/core/` 项目数据、硬件和模型加载
- `app/services/` 引擎适配和服务
- `app/widgets/` UI组件与3D视口
- `tests/` 自动化测试
- `docs/` 架构、开发计划、许可证与验收文档
- `assets/` 自制或许可已核验的资源
- `models/` 许可已核验的模型权重
