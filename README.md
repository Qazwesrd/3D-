# 3D动漫角色创作大师

独立开发的桌面端3D动漫角色创作软件。当前从零建立工程，不依赖其他项目。

## 项目原则
- 独立源码、独立安装包、独立数据目录。
- 优先采用免费且许可兼容的开源技术。
- 未经用户明确授权，不调用付费API、不自动购买或充值。
- 以 Windows + AMD Ryzen 7 4800U / Radeon 集成显卡作为基础兼容目标，实际性能以设备测试为准。
- 第三方代码、模型权重、插件和素材逐项审核许可证；仓库自身许可证不覆盖第三方资产。

## 当前状态
工程起始版 v0.1 已建立：中文桌面界面、角色项目本地管理、基础硬件信息采集、引擎接口占位。当前预览区仍是示意视图，尚未接入真实3D渲染与AI生成，不能视为完整产品。

## 目录规划
- `app/` 桌面应用程序
- `app/core/` 项目数据与硬件能力
- `app/services/` 引擎适配和服务
- `app/widgets/` UI组件与3D视口
- `tests/` 自动化测试
- `docs/` 架构、开发计划、许可证与验收文档
- `assets/` 自制或许可已核验的资源
- `models/` 许可已核验的模型权重（大文件优先使用Git LFS或外部正式发布渠道）

## 开发计划
1. 真正的3D视口与GLB导入预览
2. 基础人物网格和比例编辑
3. 文字/图片驱动的角色生成工作流
4. 发型、服装、盔甲、武器、材质编辑
5. 骨骼绑定、动作、表情与口型
6. GLB/FBX/OBJ资产导入导出
7. 显卡适配、性能优化、安装包与完整验收

详见 `docs/ROADMAP.md` 和 `docs/ARCHITECTURE.md`。
