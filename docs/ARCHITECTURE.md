# 软件架构

## 设计原则
本项目独立于AI漫剧制作大师和其他游戏项目。后续通过GLB等通用格式及稳定的项目资产接口交换角色资产。

## 模块
- UI层：PySide6桌面窗口和交互控件
- 项目层：本地角色项目JSON、资产目录和版本迁移
- 3D层：后续接入实时视口、模型导入、材质和骨骼
- AI层：后续接入可选本地推理工作流；默认关闭网络服务和付费接口
- 硬件层：CPU、RAM、GPU、图形API检测及性能档位
- 发布层：Windows安装程序、运行时和经过许可审核的基础资源

## 数据边界
用户创建的角色工程保存在用户数据目录，不放入程序安装目录。大型模型权重不直接塞入Git普通文件；在确认许可证、体积和分发方式后，再决定是否采用Git LFS或独立安装资源包。
