# 真实3D视口与模型导入

## 本阶段内容
- 使用 pyqtgraph OpenGL 视口显示三角网格。
- 使用 trimesh 读取本地 GLB、GLTF、OBJ、STL、PLY。
- 支持视口鼠标旋转、滚轮缩放、右键平移（具体交互由 pyqtgraph/OpenGL 视图控件处理）。
- 模型导入时仅在内存中居中并缩放，不覆盖原始文件。
- 将导入模型的原始路径记录到当前角色项目的资产字段。

## 当前边界
- 这是网格预览，不是完整雕刻/拓扑编辑器。
- GLTF外部贴图、复杂PBR材质、透明排序和骨骼动画的完整呈现尚未验收。
- 不同AMD驱动/OpenGL版本可能影响硬件加速；如果OpenGL初始化失败，软件显示提示，不应崩溃。
- 尚未在用户的 Ryzen 7 4800U 设备上完成实机验收。
