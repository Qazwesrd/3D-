# 开发记录

## 2026-11-21

### v0.1 工程起始版
- 建立独立工程、中文主窗口、角色项目本地JSON存储和硬件信息采集接口。

### v0.2 3D视口与模型导入
- 加入pyqtgraph/OpenGL交互视口。
- 增加trimesh本地网格加载，支持GLB、GLTF、OBJ、STL、PLY的基础网格导入。
- 主界面增加模型导入操作。

### v0.3 基础人物比例建模
- 增加程序化基础人形灰盒网格生成器。
- 加入身高、头部大小、肩宽、腰胯宽度、手臂长度、腿长参数控件。
- 参数保存在项目数据中。
- 增加当前网格导出GLB功能。
- 增加基础人形生成器自动化测试代码。
- 当前尚未在目标电脑执行实机验收。

### v0.4 面部与身体部件化
- 将角色生成器升级为具名部件字典，同时保留原有整模生成接口。
- 增加头部、耳朵、眼睛、虹膜、鼻子、嘴部、颈部、躯干、左右手臂、左右手掌（含拇指和四指）、左右腿部与脚部的独立几何。
- 增加成年男性、成年女性、少年、少女、儿童比例预设，并允许继续手动微调。
- 主界面增加身体部件列表和单部件GLB/OBJ/STL导出。
- 新增部件完整性和比例缩放测试。
- 当前仍为程序化灰盒几何，未达到生产级人体拓扑；代码提交不等于本机验收，尚未在目标电脑执行测试。
