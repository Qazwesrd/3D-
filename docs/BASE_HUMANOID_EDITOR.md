# 基础人物比例建模

## 本阶段新增
- 程序化生成一个简化的人形灰盒网格。
- 可调整身高、头部大小、肩宽、腰胯宽度、手臂长度和腿部长度。
- 生成结果显示在3D视口中。
- 支持将当前网格导出为GLB。
- 当前比例参数保存在角色项目JSON中。

## 明确限制
本阶段模型由椭球体和圆柱体组合，属于基础比例灰盒，不是精细人体拓扑，不包含可生产使用的面部结构、手指细节、服装、盔甲、头发、UV贴图、PBR材质、骨骼绑定或动画。参数改变后需要重新点击“生成基础人物”更新视口。GLB导出针对当前合并网格，不能保留完整材质层级或动画。

## 后续
下一阶段改善网格结构与身体部件可编辑性，加入脸部基础形状、手掌/脚部细节和角色分部资产管理，再进入服装与盔甲编辑。
